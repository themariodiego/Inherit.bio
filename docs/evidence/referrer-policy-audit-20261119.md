# Referrer-Policy audit of every route handler · 19 November 2026

Made for D-137 and D-138 (`docs/protocol/defects.md`). Each route handler was run through the real proxy (`src/proxy.ts`) for every registered method, signed in and signed out, and joined to the route register's `sensitiveResponseHeaders`, `sensitiveResponseHeaderBindings` and bound response contracts. "Before" is commit `29d393d5`; "after" is the commit that adds this file. It is a reading aid, not a gate: the ratchet in `src/proxy.test.ts` is what fails when the proxy stops honouring a register binding. Nothing here was observed in a browser.

# Public appeal evidence in TEST

The existing public intake and mail producer are in draft PR306. This follow-on
source connects a subject-objection or genetic-parent-objection credential to
`/withdraw/session`, where the native purpose selects its own evidence form.
An account, subject, cohort, reviewer or storage path cannot be chosen by the
request. The random case principal never acquires account authority.

Both existing TEST flags and the private native intake configuration remain
closed by default. This version completes only a **no-match** evidence set. A
same-key-revision contact HMAC potential match is refused until the separate
typed adult-confirmation/genetic-parent resolver and reversible target hold
are qualified. Access/review cannot activate because the current public intake
has no server-bound underlying decision. It is not offered a guessed proof set.

The form opens independent-key evidence sessions, writes create-only sealed
chunks into private `legal-evidence`, and uses the existing whole-EOF/hash/type
composer. A complete positive malware verdict precedes submission. An operator
can run the separate scanner with the existing installed runtime:

    node --conditions=react-server --import ./scripts/server-only-shim.mjs --import tsx scripts/appeal-document-scan-worker.run.mts --once

No scanner is started by a page request. No hosted or provider execution has
been claimed by this draft. The native transaction tests exercise actual
nonce/session/evidence/scan-record/review/disposal functions; their synthetic
scan record and deletion acknowledgment do not prove physical provider work.

Completion locks the two exact same-case/current-revision documents, consumes
the native operation nonce, creates the current named pending review, rotates
the evidence revision and consumes the rights session. Its receipt contains
only `review_pending` and the original deadline. It does not approve evidence,
grant access, apply a restriction or delete target data.

Credential validity is at most seven days, a browser rights session at most
60 minutes with a 15-minute idle limit, and the case keeps its original 30-day
deadline. Terminal case disposal erases case and independent document keys,
contact/working material and the live review assignment. Object locators stay
until exact physical deletion acknowledgment. Retention removes only native-due
objects; a storage outage cannot preserve their decryption keys. Remote provider
history/purge proof and a completed human-review decision flow remain separate.

# Saved result bases · 30 September 2026

G4.2 requires the data and display to agree about how a number was made. The vocabulary stays `observed`, `modelled` and `exact` (`src/lib/figures/contract.ts`): observations/counts from a file, statistical estimates, and arithmetic from observed inputs without an intervening model. The third value preserves the brief's exact Mendelian label (§8.4 and §A.7), rather than recategorizing it to satisfy the gate's older two-value wording.

`src/lib/figures/result-basis.ts` closes the classification receipt to exactly `{ version: 1, basis }`. Readers reject missing/unknown versions, unknown values, extra keys and a classification inconsistent with the kind they read. They return the saved value; they do not manufacture a replacement.

## Verification and remaining gaps

Focused tests exercise the real own-report execution, checked page/chat readers, closed embryo projection and rendering paths. Refusal cases include modelled-as-observed, exact-as-risk, missing receipts, unknown versions, extra fields and a changed historic basis. The pgTAP round trip uses an empty synthetic fixture generated by the actual ancestry producer, binds it to the independently prepared array source, checks the real journal and authorized reader, and verifies that the earlier revision-1 file is not backfilled. Fresh-database and full-browser verification remain release requirements.

G4.2 remains **NO**. The pending embryo publication chain sanitizes/publishes source data and has no `embryo_scores` writer. A permissible result computation, its saved-to-rendered round trip and browser proof are still required before this contract can become a shipped embryo result. Dormant `portrait_results` and `embryo_figures` tables are not made active by adding metadata to unrelated code. Unvalidated PRS quantities remain withheld by `src/lib/genome/prs-output.ts`.

There is a separate unresolved QC classification: `src/components/embryo/qc-figures.ts:4–6,70` says laboratory-reported dropout estimates are observed, while `src/lib/figures/contract.ts:32–39` calls any statistical estimate modelled. Brief §A.6 (line 2231) defines dropout/contamination estimates and the null rule without assigning their figure basis. This change preserves the existing QC contract rather than silently labeling an entire QC row. A producer-specific QC decision and strict saved metadata remain necessary. Within-family effect intervals remain modelled as statistical estimates; the word `measured` in their validation status does not turn an estimated effect into a direct source observation.
